#  Problem-Solving Approach

For every problem, I try to follow this process:

1. **Understand the Problem**
2. **Identify the Approach**
3. **Implement the Solution**
4. **Analyze Time Complexity**
5. **Analyze Space Complexity**
6. **Test the Solution**
7. **Look for Possible Improvements**

The goal is to understand the solution rather than simply getting an accepted submission.
